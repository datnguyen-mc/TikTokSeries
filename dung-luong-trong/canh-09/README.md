# Cảnh 09: Don't Sleep (Không ngủ) (4 Clips × 15s = 60s)

- **Thời gian:** Đêm ngày 6, phòng trọ (08:00–09:00)
- **Bối cảnh:** Phòng trọ lúc hai giờ sáng: đèn bàn học bật sáng, Khải ngồi tựa tường, miếng dán NeuroRent nằm trên bàn vẫn nháy tím.

- **Đạo cụ chính:** Điện thoại đang ghi âm, cốc cà phê nguội, miếng dán NeuroRent trên bàn, đèn bàn học, rèm gác xép.
