# Cảnh 05: Đế Chế Phú Quý (6 Clips × 10s = 60s)

- **Thời gian:** 10:00 Sáng (04:00–05:00)
- **Bối cảnh:** Văn phòng tổng đài công ty cho vay Phú Quý trên tầng hai mươi lăm một tòa nhà kính ở Hà Nội.
