# Cảnh 09: Kế Hoạch Rồng Về Phố (6 Clips × 10s = 60s)

- **Thời gian:** 21:00 Tối (08:00–09:00)
- **Bối cảnh:** Phố cổ về đêm rực biển neon; quán bún chả của bà Hoa sau giờ đóng cửa, nơi bộ ba bàn kế hoạch.
