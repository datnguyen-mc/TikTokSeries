# Cảnh 18: Ổ Cứng Cải Lương (6 Clips × 10s = 60s)

- **Thời gian:** 09:00 Sáng (17:00–18:00)
- **Bối cảnh:** Trước cổng đồn công an phường trên con phố rợp bóng cây.
