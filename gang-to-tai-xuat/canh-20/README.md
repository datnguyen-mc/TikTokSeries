# Cảnh 20: Buổi Livestream Định Mệnh (6 Clips × 10s = 60s)

- **Thời gian:** 20:10 Tối (19:00–20:00)
- **Bối cảnh:** Phòng sếp vách kính của Hưng trong tổng đài Phú Quý về đêm, và chiếc xe tải trắng dưới chân tòa nhà.
