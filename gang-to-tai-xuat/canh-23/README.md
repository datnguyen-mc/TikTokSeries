# Cảnh 23: Siêu Xe Kẹt Giờ Tan Tầm (6 Clips × 10s = 60s)

- **Thời gian:** 20:45 Tối (22:00–23:00)
- **Bối cảnh:** Hầm xe tòa tháp kính, rồi đại lộ Hà Nội giờ tan tầm buổi tối; cây cầu sắt bên sông ở cuối đường.
